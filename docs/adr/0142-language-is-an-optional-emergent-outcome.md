# ADR 0142: language is an optional emergent outcome

Date: 2026-08-09

Status: Accepted

## Context

The inhabitants begin without words, names, writing, dictionaries, translations, or privileged
semantic labels. Observers nevertheless need a rigorous way to research communication if repeated
signal forms and shared meanings ever emerge. Calling every signal language would manufacture the
result; translating a form without evidence would hide observer interpretation as world fact.

## Decision

Language is never a milestone, scheduled capability, reward, or guaranteed outcome. The simulator
exposes only use-neutral physical signaling, perception, memory, association, imitation, and
variation. The current substrate provides 32 physically distinguishable but semantically blank
signal forms. An inhabitant can privately associate a form heard from another individual with a
subsequently witnessed primitive action or movement direction, and that learned association can
bias its later behavior. No form begins with a meaning and no convention is scheduled. Whether
those mechanisms produce repeatable socially learned forms is part of history.

The public wiki contains an empty-by-default language archive. A dictionary entry may appear only
when a versioned deterministic detector can cite repeated committed uses of the same original form
across time and individuals. Each entry preserves:

- the original signal form without replacing it with an observer word;
- a tentative observer translation or gloss;
- deterministic confidence inputs and the detector version;
- first, latest, and representative supporting event references;
- scope and usage context;
- competing translations and later revisions without deleting earlier interpretations.

Names use the same evidence boundary. A repeated signal becomes an inhabitant-created name only if
committed behavior supports stable reference to one individual; supporter aliases and observer IDs
cannot satisfy that test. Once supported, the emergent name may become the primary public display,
while the stable numerical observer ID remains its audit reference.

Dictionary and translation records are observer projections. They never enter canonical events,
perception, cognition, Hindsight memory, action selection, or reproductive matching. No model call
may silently promote a candidate form; model-assisted research, if later offered, must remain a
separately labelled interpretation over the same cited evidence.

ADR 0144 defines the first versioned deterministic evidence threshold used by that archive.

## Consequences

- The world can remain permanently non-linguistic without being treated as stalled or incomplete.
- Proto-signals are not advertised as words merely because observers can correlate them with an
  action.
- If language emerges, observers receive a provenance-bearing dictionary and translation layer
  rather than an opaque narrative summary.
- The current bounded signal-form mechanism can support a rudimentary learned conventional lexicon,
  so language is mechanically possible rather than a promised future feature. It does not preseed
  vocabulary, guarantee convergence, or guarantee compositional grammar. Richer compositional and
  referential structures may emerge only to the extent the inhabitants' repeated physical signals,
  temporal sequences, memory, and learned behavior support them.
