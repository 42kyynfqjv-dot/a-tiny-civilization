# ADR 0162: language forms are socially retained compositions

Date: 2026-08-21

Status: Accepted; implementation in progress

## Context

The first language substrate exposes 32 distinguishable calls. That can support a
small conventional call system, but treating those calls as a vocabulary—or growing
the vocabulary through engine-awarded capacity—would preconfigure the very result
the experiment is meant to observe. Human-like productive language requires a
population to create and retain combinations, not wait for simulator milestones.

The running world's existing events and hashes must remain replayable. Reinterpreting
or widening the persisted `signal_form` field in place would violate that boundary.

## Decision

- The existing 32 signal forms remain semantically blank physical sound elements.
  They are not words and their count is not a vocabulary limit.
- The existing canonical signal event remains unchanged. A new association schema
  can retain the preceding call as well as the current call and contemporaneously
  witnessed action. Overlapping ordered pairs form longer chains without treating a
  serialized token as an engine-authored word.
- Every permitted sequence is producible from activation; there are no slots,
  levels, discoveries, population thresholds, or operator-authored unlocks.
- Every succession of independently selected calls is a possible innovation. Direct
  listeners retain both the atomic call and, within a bounded temporal window, its
  ordered transition from the source's previous call. A producer reuses a learned
  transition only when its own preceding call and embodied context match.
- Private memory is bounded by ordinary forgetting and competition. Novel sequences
  normally disappear. A population's effective vocabulary consists only of forms
  that its members repeatedly transmit and retain.
- Ordered forms can themselves occur in longer temporal sequences. The engine does
  not supply word boundaries, grammar, referents, translations, or a language goal.
- Observer dictionaries remain projections. They may publish a candidate form only
  from durable cross-individual evidence and must preserve the original element
  sequence, competing glosses, detector version, and provenance.
- Ruleset 41 uses event schema 39, state-hash schema 37, and snapshot schema 37 from
  genesis. The running ruleset-39 world activates the same driver at tick 9,200.
  Replay before that tick continues to use the old event and state shapes byte for
  byte.

## Consequences

- Vocabulary growth is generated by inhabitants and social selection rather than by
  simulator permission.
- The available physical search space can be large while each individual's learned
  repertoire remains naturally bounded.
- A shared call system may still fail to become compositional language; no positive
  outcome is scripted.
- Implementation is more involved than increasing a constant because it must add
  versioned event validation, bounded sequence memory, imitation and contextual
  reuse, snapshot/replay support, and sequence-aware observer evidence together.
